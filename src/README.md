# 🪜사다리 타기 게임

## 프로젝트 개요

사용자들로부터 참여자 이름과 실행 결과를 입력받아 사다리 타기 게임을 시뮬레이션하고, 최종적으로 이름별 매칭 결과를 조회하는 자바 애플리케이션입니다.

---
## 기능 요구사항

### 1. 입력 및 데이터 검증
- **참여자 이름 입력**
    - 쉼표(,)를 기준으로 구분하여 입력받습니다.
    - 검증: 이름은 **최대 5글자**까지 가능하며, 비어 있거나 공백일 수 없습니다.
- **실행 결과 입력**
    - 사다리의 최종 도착 지점에 표시될 결과를 입력받습니다.
    - 검증: 참여자 수와 실행 결과의 수는 반드시 일치해야 합니다.
- **사다리 높이 입력**
    - 1 이상의 양의 정수를 입력받습니다.
- **조회할 이름 입력**
    - 결과를 보고 싶은 사람의 이름을 입력받습니다.
    - `all`을 입력할 경우 참여자 전체의 결과를 출력합니다.
- **재시도 로직**: 잘못된 입력 시 `[ERROR]` 메시지를 출력하고 해당 부분부터 다시 입력을 받습니다.

### 2. 사다리 생성 및 게임 로직
- **사다리 생성 규칙**
    - 가로줄(Bridge)은 연속해서 생성되지 않도록 설계합니다.
    - 무작위성 또는 특정 전략(`BooleanGenerator`)에 따라 가로줄 생성 여부를 결정합니다.
- **결과 매칭 로직**
    - 각 참여자가 사다리를 타고 내려가 최종 도착하는 인덱스를 계산합니다.
    - 계산된 인덱스를 바탕으로 참여자와 실행 결과를 일대일 매칭하여 보관합니다.

### 3. 결과 출력
- **사다리 출력**: 참여자 이름, 사다리 구조, 실행 결과를 시각적으로 정렬하여 출력합니다.
- **개별 결과 출력**: 특정 인물 입력 시 해당 인물의 당첨 결과를 출력합니다.
- **전체 결과 출력**: `all` 입력 시 `이름 : 결과` 형식으로 모든 참여자의 매칭 정보를 출력합니다.

│   ├── Validator.java                  # 사다리 사양 및 입력 검증
│   └── LadderGameController.java       # 게임 실행 및 반복 흐름 제어
├── domain
│   ├── Player.java                     # 참여자 정보 (이름 검증)
│   ├── Players.java                    # 참여자 일급 컬렉션

│   ├── Prizes.java                     # 실행 결과 목록 일급 컬렉션

│   └── strategy

│   └── OutputView.java                 # 사다리 및 결과 출력
├── AppConfig.java                      # 의존성 주입 및 설정
