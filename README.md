# 사다리

### 사다리 게임
네이버 사다리 게임을 참고하자
1. 명수를 입력하면 그 만큼 열이 생김
2. 이름과 당첨항목 적음
3. 사다리 시작하면 행이 생김
4. 전체 결과 출력

### 현재 필요하다고 느끼는 클래스
- InputView, OutputView
- Domain
  - 참석하는 사람
  - 당첨 항목
  - 사다리 (사다리 높이, 참석하는 사람의 수)
    - 사다리 타는 로직 
  - 사다리 결과

## 1단계 - 사다리 출력
### 기능 요구사항
1. 사다리는 4*4 크기로 고정. 연결 여부는 랜덤
2. 사다리 타기가 정상적으로 동작하려면 라인이 겹치지 않도록 해야 한다
   - |-----|-----| 모양과 같이 가로 라인이 겹치는 경우 어느 방향으로 이동할지 결정할 수 없다.

### 추가 요구사항
1. 모든 엔티티를 작게 유지한다
2. 3개 이상의 인스턴스 변수를 가진 클래스를 쓰지 않는다 
3. 모든 원시 값과 문자열을 포장한다
4. 일급 컬렉션을 쓴다
5. Java Enum을 적용한다

### 구현 방식
Ladder라는 클래스를 만든다
해당 클래스는 column(열), row(행)을 필드로 가지고 있다
ArrayList<ArrayList<boolean>> ladder 를 가진다고 생각
