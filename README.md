# 1단계 - 사다리 출력
## 기능 요구사항
- 사다리는 4x4 크기로 고정되고, 연결 여부는 랜덤으로 결정한다. 
- 사다리 타기가 정상적으로 동작하려면 라인이 겹치지 않도록 해야 한다.
