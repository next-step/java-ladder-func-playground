# 사다리 게임

## 프로젝트 개요

사다리 게임 프로그램을 구현했습니다.  
사용자는 참여할 사람 이름과 실행 결과를 쉼표(,) 기준으로 입력하고, 사다리의 최대 높이를 입력할 수 있습니다.  
프로그램은 입력된 사람 수와 높이에 맞게 사다리를 생성하고, 각 참여자가 사다리를 탄 뒤 도착한 위치의 실행 결과를 매칭합니다.

사다리 출력 시 참여자 이름과 실행 결과를 함께 출력합니다.  
이후 결과를 확인하고 싶은 사람 이름을 입력하면 해당 참여자의 결과를 출력하고, `all`을 입력하면 전체 참여자의 실행 결과를 출력합니다.

## 기술 스택

- Java
- Gradle
- JUnit5
- AssertJ

## 구현 기능

### Player

- 사다리 게임에 참여하는 한 명의 플레이어를 관리한다.
- 플레이어 이름과 현재 위치를 함께 관리한다.
- 플레이어 이름이 비어 있으면 예외를 발생시킨다.
- 플레이어 이름이 5자를 초과하면 예외를 발생시킨다.

### Players

- 여러 명의 플레이어를 관리한다.
- 플레이어 이름 목록을 받아 각 플레이어에게 위치를 부여한다.
- 플레이어 이름이 중복되면 예외를 발생시킨다.
- 플레이어 목록을 반환한다.
- 출력에 사용할 플레이어 이름 목록을 반환한다.
- 플레이어 수를 반환한다.

### Row

- 사다리의 한 행을 관리한다.
- 연결선이 생성된 다음 위치에는 연결선이 연속으로 생성되지 않도록 처리한다.
- 현재 위치 기준으로 왼쪽에 연결선이 있으면 왼쪽으로 이동한다.
- 현재 위치 기준으로 오른쪽에 연결선이 있으면 오른쪽으로 이동한다.
- 이동할 연결선이 없으면 현재 위치를 유지한다.

### Ladder

- 여러 개의 `Row`로 구성된 사다리를 관리한다.
- 입력받은 높이만큼 사다리 행을 생성한다.
- 사다리 높이가 1보다 작으면 예외를 발생시킨다.
- 시작 위치를 받아 사다리의 각 행을 위에서 아래로 순서대로 지나 최종 위치를 반환한다.

### LadderResult

- 사다리 게임의 실행 결과 목록을 관리한다.
- 입력받은 실행 결과를 저장한다.
- 실행 결과 목록을 반환한다.

### LadderGame

- 사다리 실행을 담당한다.
- 각 플레이어가 사다리를 탄 뒤 도착한 위치를 계산한다.
- 도착한 위치에 있는 실행 결과를 플레이어 이름과 매칭한다.
- 최종 결과를 `Map<String, String>` 형태로 반환한다.

### PrizeResult

- 한 명의 플레이어 이름과 실행 결과를 함께 관리한다.
- `Map.Entry<String, String>` 형태의 결과를 출력용 결과 객체로 변환한다.

### PrizeResults

- 여러 명의 실행 결과를 관리한다.
- 사다리 게임 결과를 `PrizeResult` 목록으로 변환한다.
- 플레이어 이름으로 개인 실행 결과를 찾는다.
- 존재하지 않는 플레이어 이름을 조회하면 예외를 발생시킨다.
- 전체 실행 결과 목록을 반환한다.

### ConnectionGenerator

- 사다리 연결선 생성 역할을 분리하기 위해 `ConnectionGenerator` 인터페이스를 사용했다.

### RandomConnectionGenerator

- `Random`을 사용하여 사다리 연결 여부를 무작위로 생성한다.

### InputView

- 참여할 사람 이름을 입력받는다.
- 사람 이름은 쉼표(,)를 기준으로 구분한다.
- 실행 결과를 입력받는다.
- 실행 결과는 쉼표(,)를 기준으로 구분한다.
- 사다리의 최대 높이를 입력받는다.
- 결과를 보고 싶은 사람 이름을 입력받는다.

### OutputView

- 사다리 결과를 출력한다.
- 참여자 이름을 사다리 위에 함께 출력한다.
- 사다리 연결 상태를 출력한다.
- 실행 결과를 사다리 아래에 함께 출력한다.
- 개인별 실행 결과를 출력한다.
- 전체 참여자의 실행 결과를 출력한다.
- 예외 메시지를 출력한다.

### LadderController

- 사다리 게임의 전체 진행을 담당한다.
- 참여자 입력, 실행 결과 입력, 사다리 높이 입력을 순서대로 처리한다.
- 입력값이 유효하지 않으면 에러 메시지를 출력하고 다시 입력받는다.
- 사다리 생성 후 사다리와 실행 결과를 출력한다.
- 개인별 결과 조회를 반복해서 처리한다.
- `all`을 입력하면 전체 실행 결과를 출력하고 결과 조회를 종료한다.

## 테스트

### PlayerTest

- 이름이 5자를 초과하면 예외가 발생하는지 테스트한다.
- 이름을 입력하지 않으면 예외가 발생하는지 테스트한다.

### PlayersTest

- 플레이어 이름이 중복되면 예외가 발생하는지 테스트한다.

### RowTest

- 연결선이 생성된 다음 위치에는 연결선이 생성되지 않는지 테스트한다.
- 오른쪽에 연결선이 있으면 오른쪽으로 이동하는지 테스트한다.
- 왼쪽에 연결선이 있으면 왼쪽으로 이동하는지 테스트한다.
- 연결선이 없으면 움직이지 않는지 테스트한다.

### LadderTest

- 사다리의 높이가 1보다 작으면 예외가 발생하는지 테스트한다.
- 입력한 높이만큼 사다리 행이 생성되는지 테스트한다.
- 사다리가 여러 `Row`를 위에서 아래로 순서대로 적용하는지 테스트한다.

### LadderGameTest

- 사다리 실행 결과의 위치에 있는 상품을 플레이어에게 매칭하는지 테스트한다.

### TestConnectionGenerator

- 테스트에서 원하는 연결 정보를 고정으로 생성하기 위해 사용한다.
- 예측 가능한 사다리 구조를 만들어 `Row`, `Ladder`, `LadderGame`의 동작을 검증한다.

## 설계 의도

사다리 게임의 핵심 도메인을 `Player`, `Players`, `Row`, `Ladder`, `LadderGame`으로 분리했습니다.  
`Player`는 한 명의 참여자와 위치를 관리하고, `Players`는 참여자 목록을 일급 컬렉션으로 관리하도록 구성했습니다.

사다리의 한 줄은 `Row`가 담당하고, 전체 사다리는 `Ladder`가 여러 `Row`를 관리하도록 했습니다.  
이를 통해 사다리 이동 규칙과 전체 사다리 실행 흐름을 분리했습니다.

연결선 생성 방식은 `ConnectionGenerator` 인터페이스로 분리했습니다.  
운영 코드에서는 `RandomConnectionGenerator`를 사용해 무작위 연결선을 생성하고, 테스트 코드에서는 `TestConnectionGenerator`를 사용해 고정된 연결 정보를 주입했습니다.  
이 구조를 통해 랜덤 요소가 있는 사다리 생성 로직도 테스트 가능한 형태로 만들었습니다.

사다리 실행 결과는 `LadderGame`에서 계산하도록 했습니다.  
`LadderGame`은 플레이어가 사다리를 탄 뒤 도착한 위치를 계산하고, 해당 위치의 실행 결과를 플레이어 이름과 매칭합니다.

출력에 필요한 결과 데이터는 `PrizeResult`, `PrizeResults`로 분리했습니다.  
`PrizeResults`는 전체 실행 결과 목록을 관리하고, 플레이어 이름으로 개인 결과를 조회하는 책임을 가집니다.

입력과 출력은 `InputView`, `OutputView`로 분리했습니다.  
`LadderController`는 입력, 도메인 실행, 출력 흐름을 조율하는 역할e만 담당하도록 구성했습니다.
